Тип имущественного комплекса - это основной реквизит Имущественного комплекса. Предназначен для дифференциации Имущественных комплексов по выбранному критерию. Количество Типов имущественных комплексов не ограничивается.

На уровне каждого отдельного Типа имущественного комплекса есть возможность определить внешний вид карточки Имущественного комплекса, особенности нумерации, статусную схему, а также значения по умолчанию для единиц измерения.

Рекомендация

Выделять разные Типы имущественных комплексов имеет смысл, если для разных имущественных комплексов требуется управлять внешним видом карточки, проверками, иметь разный набор статусов. Например, для имущественных комплексов, которые относятся к разным видам бизнеса могут быть созданы отдельные Типы, каждый со своим пользовательским интерфейсом и статусной схемой. Для имущественных комплексов, которые располагаются в разных странах с разной системой мер также целесообразно создавать отдельные типы, т.к. основные единицы измерения могут отличаться. Например, в разных странах длина может измеряться в метрах, милях, футах.

Описание настройки:

  • Код - Указывается условное обозначение для Типа имущественного комплекса. Поле является обязательным для заполнения. Длина - 4 символа.  
  • Наименование - Содержит краткое (до 25 символов) наименование для Типа имущественного комплекса. Поле обязательное для заполнения.
  • Полное наименование - Содержит описание (длинный текст) для Типа имущественного комплекса. 
  • Имя формы - Указывается имя формы, которая используется для представления Имущественных комплексов данного типа. Поле обязательное для ввода. 
  • Статусная схема - Статусная схема, которая используется для Имущественных комплексов данного типа. Статусная схема определяет набор возможных пользовательских статусов объектов, а также возможную последовательность их изменения. 
  • Разделитель - символ, который используется в представлении поля "Идентификатор" Имущественных комплексов данного типа (пример идентификатора, разделитель выделен цветом: "ИК АА/000000001"). Не рекомендуется изменять значение данного реквизита после того, как в системе уже были созданы объекты данного типа. Поле является обязательным для ввода. По умолчанию предлагается использовать символ "/".
  • Выводить лидирующие нули - Определяет представление номера в поле "Идентификатор" Имущественных комплексов данного типа. Если опция не активна, номер выводится без лидирующих нулей, например, "ИК АА/1". Если опция активна, номер выводится с лидирующими нулями: , например, "ИК АА/000000001".
  • Единицы измерения по умолчанию - указываются единицы измерения, которые будут использоваться по умолчанию в Имущественных комплексах данного типа и в подчиненных объектах для указания значений длины, объема и площади.
