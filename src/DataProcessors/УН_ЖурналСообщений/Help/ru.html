Обработка предназначена для анализа Журналов сообщений, возникших при выполнении определенных действий, например, в результате проведения документов, выполнения обработок, процессов и т.д.

Основные термины и понятия

  • Журнал сообщений - Совокупность Списков сообщений, каждый из которых относится к одному событию (операции, транзакции).
  • Объект Журнала сообщений - Критерий, который используется для дифференциации Списков сообщений и указания принадлежности к какому-либо объекту системы, операции или обработке. Объекты Журнала сообщений определяются разработчиком.
  • Список сообщений - Состоит из заголовка и табличной части — списка сообщений.
  • Внутренний ключ - Произвольный текст, который может быть использован для записи вспомогательной информации, например, идентификатора объекта. Используется в качестве вспомогательного идентификатора для более точного поиска нужного Журнала.

Работа с обработкой

Для работы с обработкой "Журнал сообщений" выполните следующие шаги:

  1. Заполнение критериев выбора (опционально):

    2. На вкладке "Критерии поиска" укажите значения для ограничения выборки по требуемым параметрам.

  • Объект: Поддерживается выбор из справочника. Допускается множественный выбор.
  • ВнутреннийКлюч: Укажите значение внутреннего ключа, если знаете. Можно задавать значения по маске. Используйте символы: "%" - последовательность, содержащая любое количество произвольных символов или "_" - один произвольный символ. Например: "ИК ЛЮ/%" - будут отобраны Журналы сообщений у который в поле ""Внутренний ключ"" указан текст, начинающийся на "ИК ЛЮ" и заканчивающийся на любое количество символов.
  • Пользователь: Позволяет ограничить выборку по Пользователям, от имени которых создан Журнал сообщений. Значение можно выбрать из списка пользователей. Допускается множественный выбор.
  • Временной интервал: Укажите границы временных интервалов для местного часового пояса для ограничения выборки.

  1. Поиск: Нажмите кнопку "Выполнить" или клавишу F5 на клавиатуре для выполнения поиска. В результатах поиска отобразится список Журналов сообщений, удовлетворяющих критериям выбора.
  2. Просмотр сообщений: Выделите в результатах поиска требуемый Журнал сообщений, в нижней части формы отобразится список сообщений, относящихся к Журналу.

Рекомендации по использованию

  1. Регулярно просматривайте журнал сообщений, чтобы быть в курсе событий и изменений в системе управления недвижимостью
  2. Используйте функцию фильтрации, чтобы быстро находить нужную информацию, указывая точные критерии отбора.
  3. При задании критериев отбора по времени, убедитесь, что указано местное время, чтобы получить корректные результаты.
  4. Используйте возможность поиска по внутреннему ключу с маской, чтобы находить сообщения, содержащие определенные ключевые фрагменты.
  5. Используйте функцию сортировки, чтобы упорядочить список сообщений по времени или уровню важности.
